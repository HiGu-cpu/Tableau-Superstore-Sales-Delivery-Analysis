# Tableau Final Project – Superstore Sales and Delivery Analysis

This project was created as part of my Tableau data analytics coursework.  
The main goal of the project is to analyze sales performance, customer segments, product categories, and delivery trends using the Superstore dataset.

## Project Overview

In this dashboard, I analyzed how sales and profit change across different categories, regions, customer segments, and shipping methods. I also focused on delivery performance to understand how shipping choices may affect business operations.

## Key Insights

- Sales and profit can be compared by category, sub-category, and region.
- Delivery performance can be analyzed based on shipping mode and order dates.
- The dashboard helps users quickly understand business performance and possible areas for improvement.
- Filters allow the user to explore the data interactively.
